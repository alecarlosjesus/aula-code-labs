No TypeScript, antes de criar dados, criamos um contrato (ou uma ficha cadastral)[cite: 2]. Isso ensina ao editor exatamente quais campos todo produto precisa ter[cite: 2]. Se esquecermos uma vírgula ou escrevermos o nome do campo errado, o TypeScript avisa na hora[cite: 2].

  1. Dentro da pasta src, crie uma pasta chamada types[cite: 2].
  2. Dentro dela, crie o arquivo types.ts[cite: 2].
  3. Adicione o seguinte código[cite: 2]:
// src/types/types.ts

// 'export' permite que esse molde seja usado em outros arquivos.
// 'interface' é a palavra-chave para criar o contrato de estrutura.
export interface TipoProduto {
  // 'id' é numérico. Exemplo: 1, 2, 3.
  id: number;          
  
  // 'nome' é texto (string). Exemplo: "Teclado Mecânico".
  nome: string;        
  
  // 'preco' é numérico. Não usamos "R$", apenas decimais. Ex: 299.90.
  preco: number;       
  
  // 'descricao' é texto curto explicando o item.
  descricao: string;   
  
  // 'avatar' é texto (string) contendo a URL da imagem.
  avatar: string;      
}

Abra o arquivo do seu componente que já existe: src/routes/Produtos/index.tsx[cite: 2]. Para fazer esse componente funcionar, precisaremos de duas ferramentas especiais do React chamadas Hooks[cite: 2]:

  • useState: É a gaveta da memória do componente[cite: 2]. Toda vez que você guarda algo nela usando a função set..., o React descobre que tem novidade e repinta a tela para mostrar os dados atualizados[cite: 2].
  • useEffect: É um vigia que espera a tela carregar[cite: 2]. Imagine que o componente acabou de ser colocado na tela pela primeira vez (a gente chama isso de "montagem")[cite: 2]. O useEffect percebe isso e dispara uma ação que você programou, como por exemplo: "Agora que a tela abriu, busque a lista de produtos e guarde na gaveta!"[cite: 2].

Uma tabela na web funciona como uma planilha de caderno[cite: 2]:

  • : A tabela inteira[cite: 2].
    • : O cabeçalho (a primeira linha que diz o nome de cada coluna)[cite: 2].
    • : O corpo da tabela, onde moram os dados reais[cite: 2].
    • : Uma linha inteira (Table Row)[cite: 2].
    • na tabela[cite: 2].

    Substitua o conteúdo de src/routes/Produtos/index.tsx pelo código documentado abaixo, formatado com a temática visual Cyberpunk Neon:

    // 1. Ferramentas essenciais do React
import { useState, useEffect } from 'react';

// 2. Importação do Contrato (Tipagem) e dos Dados
import { TipoProduto } from '../../types/types';
import { listaProdutos } from '../../data/listaProdutos';

export default function Produtos() {
  // O Hook useState prepara a memória. 
  // 'produtos' = a lista atual (começa vazia: []).
  // 'setProdutos' = o controle remoto que atualiza essa lista.
  const [produtos, setProdutos] = useState<TipoProduto[]>([]);

  // O Hook useEffect dispara quando a tela "nasce".
  useEffect(() => {
    // Ação: Pega os dados do arquivo e salva na memória do componente.
    setProdutos(listaProdutos);
    
    // O array vazio [] garante que isso aconteça APENAS UMA VEZ.
  }, []);

  return (
    <main style={{ padding: '20px', fontFamily: 'sans-serif', backgroundColor: '#0d0d0d', color: '#39ff14', minHeight: '100vh' }}>
      <h1>Painel de Produtos</h1>
      <p>Confira abaixo a lista de itens cadastrados no sistema:</p>

      {/* Tabela estilizada em formato Neon/Dark */}
      <table border={1} cellPadding={10} style={{ width: '100%', borderCollapse: 'collapse', textAlign: 'left', borderColor: '#39ff14' }}>
        
        {/* Cabeçalho da Tabela */}
        <thead>
          <tr style={{ backgroundColor: '#1a1a1a', color: '#ff00ff' }}>
            <th>Foto</th>
            <th>ID</th>
            <th>Nome</th>
            <th>Preço</th>
            <th>Descrição</th>
          </tr>
        </thead>

        {/* Corpo da Tabela com a repetição automática usando .map() */}
        <tbody>
          {produtos.map((item) => (
            // A 'key' ajuda o React a não se perder ao renderizar listas. 
            // Exemplo: Se o ID for 1, a key será 1.
            <tr key={item.id} style={{ borderBottom: '1px solid #39ff14' }}>
              
              {/* Coluna da Imagem */}
              <td>
                <img 
                  src={item.avatar} 
                  alt={item.nome} 
                  width={60} 
                  height={60} 
                  style={{ objectFit: 'cover', borderRadius: '4px', border: '1px solid #ff00ff' }} 
                />
              </td>
              
              {/* Coluna do ID */}
              <td>{item.id}</td>
              
              {/* Coluna do Nome */}
              <td><strong>{item.nome}</strong></td>
              
              {/* Coluna do Preço formatado com duas casas decimais */}
              <td>R$ {item.preco.toFixed(2)}</td>
              
              {/* Coluna da Descrição */}
              <td>{item.descricao}</td>
            </tr>
          ))}
        </tbody>
      </table>
    </main>
  );
}

    Para mostrar vários produtos sem ter que digitar um por um manualmente, usamos a função do JavaScript chamada .map()[cite: 2]. O .map() funciona como uma esteira de fábrica: ele pega cada item da nossa lista, um por um, e transforma em uma linha
