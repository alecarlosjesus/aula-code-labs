Bem-vindo ao esquadrão, recruta! Antes de tocarmos no código, você precisa entender como os computadores do laboratório da FIAP funcionam.

As máquinas utilizam um sistema de "congelamento" de disco. Isso significa que absolutamente tudo que for salvo no disco C:\ (Documentos, Área de Trabalho, Downloads) será vaporizado assim que o computador for reiniciado.

Para não perder horas de código, siga a regra de ouro:

  1. Abra o Explorador de Arquivos.
  2. Acesse a unidade D:\ (Dados).
  3. Crie uma pasta com o nome da sua turma (Ex: 1TDSPX).
  4. Todo o seu trabalho do semestre será feito dentro desta pasta!

Você acabou de sentar no laboratório. A máquina foi reiniciada e está totalmente limpa. O código da aula passada está seguro na nuvem (GitHub), mas você precisa trazê-lo para o disco D:\.

Abra a sua pasta no disco D:\, clique com o botão direito do mouse no fundo branco e escolha "Open Git Bash here".

Passo 1: A Identificação

Como a máquina "esqueceu" quem é você, o Git vai bloquear qualquer tentativa de salvar código se você não se identificar. Digite os comandos abaixo:

git config --global user.name "Seu Nome e Sobrenome"
git config --global user.email "rm12345@fiap.com.br"

Dissecando o comando:

  • git config: Chama a ferramenta de configurações internas do Git.
  • --global: Diz que essa regra vale para todos os projetos que você abrir neste computador hoje.
  • user.name / user.email: São as credenciais do seu "crachá". Elas carimbam a sua autoria em cada linha de código alterada.

Passo 2: O Download e Acesso

Agora vamos clonar o repositório oficial e abrir o editor de código:

git clone https://github.com/1TDSPX/nome-do-repositorio.git
cd nome-do-repositorio
code .

Dissecando o comando:

  • git clone [URL]: Conecta no servidor do GitHub e faz um download completo do projeto para a sua pasta.
  • cd nome-do-repositorio: O comando cd significa Change Directory (Mudar de Diretório). Ele faz o terminal "entrar" na pasta que acabou de ser baixada. Se não fizer isso, os próximos comandos darão erro!
  • code .: O code chama o Visual Studio Code. O espaço seguido de ponto . significa "abra exatamente a pasta onde estou agora".

Você chegou em casa. O seu notebook pessoal já tem o projeto clonado das semanas anteriores (você não precisa dar git clone de novo e nem configurar o seu nome).

Porém, o código que está no seu notebook está desatualizado, pois não tem as alterações que você fez hoje de manhã no laboratório da FIAP.

Abra a pasta do projeto no seu computador, clique com o botão direito e abra o Git Bash.

git pull origin nome-da-branch
code .

Dissecando o comando:

  • git pull: Comando de puxar. Ele acessa a nuvem e traz apenas as atualizações novas para a sua máquina.
  • origin: É o nome de código padrão que o Git dá para o servidor do GitHub.
  • nome-da-branch: É o nome exato da ramificação em que você estava trabalhando na faculdade (ex: feature/site-inicial).
  • code .: Abre o VS Code para você continuar programando exatamente de onde parou.

Sempre que formos começar um assunto novo (ex: sair da aula de HTML e entrar em CSS), nunca codificamos por cima do que já está feito. Criamos uma nova ramificação (branch) isolada a partir da base principal (main).

Abra o Git Bash dentro do projeto e execute a sequência tática:

git switch main
git pull origin main
git switch -c feature/nova-aula
code .

Dissecando os comandos:

  • git switch main: Retorna você para o tronco principal da árvore do projeto.
  • git pull origin main: Atualiza o tronco principal. Garante que você está partindo do código mais recente aprovado pelo professor.
  • git switch -c feature/nova-aula: Cria e já entra em um "galho" novo. A letra -c significa create (criar). O nome do galho deve ser a missão do dia.
  • code .: Abre o editor para você trabalhar de forma segura, sem risco de quebrar o projeto principal.

A aula acabou e você precisa ir embora. Lembra que a máquina da FIAP vai apagar tudo quando reiniciar? Você é obrigado a mandar o seu código para a nuvem antes de fechar o VS Code!

Abra o terminal integrado do VS Code (ou o Git Bash) e execute:

git add .
git commit -m "feat: salvando progresso da aula de hoje"
git push -u origin feature/nova-aula

Dissecando os comandos:

  • git add .: O ponto . pega todos os arquivos modificados e os coloca na "área de preparação" (como se estivesse empacotando os itens em uma caixa).
  • git commit -m "mensagem": Fecha a caixa com fita adesiva e cola uma etiqueta (a mensagem) dizendo o que tem lá dentro.
  • git push: Empurra a caixa para o servidor do GitHub.
  • -u origin feature/nova-aula: O -u cria um elo entre a sua máquina e a nuvem, enviando a sua branch para o servidor origin. (Nas próximas vezes dentro desta mesma branch, você só precisará digitar git push).
